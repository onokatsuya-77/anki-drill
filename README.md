# 暗記ドリル（予習シリーズ 5年下 社会・漢字とことば）

毎日少しずつ解いて、忘れるころにもう一度出す暗記ドリルです。
いまの中身は、5年下 第1〜6回の598語です。

| 教科 | 中身 |
| --- | --- |
| 社会 | 語句299語（旧石器時代〜鎌倉時代）、並べかえ19セット、つまずきポイント33項目 |
| 漢字 | 書き取り152語（各回の新出漢字10字を使う語） |
| ことば | 147語（和語・慣用句・三字の熟語・四字熟語） |

## 開き方

- タブレットのブラウザで、このリポジトリの公開ページを開きます。
- 記録は**その端末のブラウザの中**に残ります。いつも同じ端末・同じブラウザで使ってください。

## 毎日のやり方（15分くらい）

1. 「きょう」の画面で、上から順にボタンを押す。
2. 問題を読んで、答えを**紙に漢字で書く**。
3. 「答えを見る」を押して、自分で採点する。

| 採点 | 意味 | 次に出る日 |
| --- | --- | --- |
| ○ | 漢字で正しく書けた | 間があく（1→3→7→14→30→60→120日後） |
| △ | 答えは合っていたが、漢字をまちがえた（社会だけ） | 明日。「社会の漢字の練習」にも入る |
| × | 答えがわからなかった | 明日 |

- 新しい語は1回に社会20語・漢字10語・ことば10語まで、復習は1日30語までです（復習の上限は「ノート」の設定で変えられます）。
- 前の回でまだ解いていない語は、1日10語ずつ出ます。
- 漢字は、文の【 】の部分を漢字で書きます。ことばは、意味と用例を見て、ことばを答えます（ひらがなでもよい）。
- △と×の語は、2回つづけて○になるまで「印つき」として残ります。

## 5つの画面

| 画面 | 内容 |
| --- | --- |
| きょう | 今日やること。新しい語 → 復習 → 組分け範囲の弱点 → 前の回の未回答 の順 |
| 回べつ | 教科と回ごとの進み具合。未回答・印つきだけを選んで解ける |
| 並べかえ | できごとを古い順にならべる |
| ノート | 印つきの語、漢字ミスの語、復習の予定、設定、記録の保存 |
| 解説 | 社会の、似ていてまぎらわしいものの見くらべ |

## つきそう人へ

- 「ノート」の設定で、**今週の回**を毎週切りかえてください。
- テストの日程（組分けテスト 11月8日・12月13日・1月24日、志望校判定テスト 1月11日）は入れてあります。テストの7日前から、弱点を先に出します。
- 塾のプリントや週テストでまちがえた語は、「ノート」の検索から印をつけられます。
- **週に1回、「ノート」→「記録をコピー」**で記録を保管してください。ブラウザの閲覧データを消すと、記録も消えます。

## 前の「社会 暗記ドリル」からの引き継ぎ

- 同じ端末・同じブラウザで開くと、前のドリルの記録を自動で読み込みます。
- 読み込まれないとき：前のドリルの「ノート」→「保存・読み込み」で文字をコピーし、このドリルの「ノート」→「記録の保存・読み込み」に貼りつけて「読み込んで合わせる」。

## 中身

`index.html` 1ファイルだけで動きます。問題は各回の単元に沿って独自に作ったものです。
