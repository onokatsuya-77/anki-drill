# 暗記ドリル（予習シリーズ 社会・漢字とことば）

毎日少しずつ解いて、忘れるころにもう一度出す暗記ドリルです。
いまの中身は、5年下 第1〜11回の1538語と、これまでの範囲（4年上・4年下・5年上）の2213語です。

| 教科 | 中身 |
| --- | --- |
| 社会 | 語句907語（旧石器時代〜江戸時代の中ごろ。週テスト・組分けテストで抜けていた139語を2026年11月10日に追加）、並べかえ39セット、つまずきポイント78項目。「まとめ・記述」17問（第9回12問・第11回5問）は当面出さない（下記） |
| 漢字 | 書き取り377語（各回の練習問題・確認問題の40語＋用例の語）＋ これまでの範囲 1880語（4年上640語・4年下600語・5年上640語。各回の確認問題の40語） |
| ことば | 254語（和語・慣用句・三字の熟語・四字熟語・同音異義語・同訓異字・第10回 総合・外来語）。当面は、塾の暗記カードがある178語だけを出す ＋ 5年上の333語（塾の暗記カード 第1〜19回の全語） |

## 開き方

- タブレットのブラウザで、このリポジトリの公開ページを開きます。
- 記録は**その端末のブラウザの中**に残ります。
- 「ノート」でログインすると、記録がクラウドにも保存され、ログインしたほかの端末と同じ記録になります（下の「端末どうしの同期」）。

## 毎日のやり方（15分くらい）

1. 「きょう」の画面で教科（社会・漢字・ことば）を押し、出てきたメニューの上から順にボタンを押す（下の「教科のメニュー」）。
2. 問題を読んで、答えを**紙に漢字で書く**。
3. 「答えを見る」を押して、自分で採点する。

| 採点 | 意味 | 次に出る日 |
| --- | --- | --- |
| ○ | 漢字で正しく書けた | 間があく（1→3→7→14→30→60日後）。60日あけて○なら「殿堂入り」 |
| △ | 答えは合っていたが、漢字をまちがえた（社会だけ） | 明日。「社会の漢字の練習」にも入る |
| × | 答えがわからなかった | 明日 |

- **社会（今週の回）は「1日で1周」**します。
  - 1日目：「社会 第9回 1周目　のこり112語」を、20語ごとに区切りながら最後まで解きます。おわりの画面の「続けて20語」で、そのまま先へ進めます。1日で終わらなければ、次の日に続きから出ます。**1周目が終わるまで、社会のメニューにはほかのボタン（復習・とことん練習など）は出ません**（その回で最初の1周目のときだけ）。あとからその回に語が増えたときは、1周目には戻らず「きょうの1周」に入ります。
  - 2日目から：「社会 第9回 きょうの1周」として、まだ危ない語（×・△だった語と、○がまだ1日だけの語）を毎日1周します。2日続けて○になった語は外れて、ふつうの復習の予定（3日後・7日後…）にもどります。
  - 週テストの前日（はじめは金曜日）：「週テスト前日の1周」として、全部をもう1周します。週テストの曜日は「ノート」の設定で変えられます。
  - 今週の回の社会は周回で出るので、「社会の復習」には入りません（2日続けて○で外れた語は、予定の日が来れば「社会の復習」に出ます）。
  - **まとめ・記述の問題**：理由を説明する問題や年号のまとめなど、一問一答にならない長い記述の問題（第9回に12問、第11回に5問）は、当面は1周・復習に出しません。「回べつ」の「まとめ・記述」ボタンでいつでも練習でき（記録もつきます）、「ノート」の設定「社会のまとめ・記述の問題」を「1周・復習にも出す」にすると、ほかの語と同じように出ます。出さない間も記録は残ります。
- 漢字の新しい語は1回に20語までです。
- ことばは、新しい語・復習に分けず、**今週の回のカード全部を毎日1回ずつ**解きます。途中でやめると、のこりの語だけがもう一度出ます。全部解くと、その日のことばの段は消え、次の日にまた全部出ます。
- **総合の回（第10回）**：ことばの「今週の回のカード」は、総合の塾のカードの45語です（第6〜9回の語44と、新しい語「つつがなく」）。カードの順に出ます。この週は、これらの語は「ことばの復習」には入りません。社会の新しい回がない間は、社会は第9回の周回（1周目・きょうの1周）を続けます。
- **復習（3教科とも同じ）**：教科のメニューの「○○の復習 20語」で解きます。出す順は、予定の日が来た語 → 印つきの語 → **前の範囲**（前の回と、4年上・4年下・5年上）でまだ解いていない語です。1回のうち2割（20語なら4語）は、前の範囲のまだ解いていない語から出します。×の語は3問あと、△の語は6問あと（のこりが足りなければ早めに）にもう一度出て、○になるまでくり返します。何度でもでき、おわりの画面の「続けて20語」で先へ進めます。1回の語数は「ノート」の設定で10語・30語にもできます。
- **復習の1日の目安は60語**（「ノート」の設定で変えられます）で、教科ごとに分けて「きょうやること」に出ます。ある教科に出す語がない日は、その分をほかの教科に回します。目安を達成すると、復習のボタンは点線（やりたいときにやる練習）になり、そこから解いた語は**積み上げの輪**に数えます。
- 前の範囲の語は習った語なので、初めて解いて○なら、次は7日後に出ます（×なら1日後から）。
- 予定の語は、「予定からの遅れ÷間隔」の大きい順に出ます。予定より大きく遅れても○だった語は、次の間隔を1段よけいに延ばします。
- **殿堂入り**：60日あけて○だった語は殿堂入りになり、きょうの画面には出なくなります。20問などで×になれば、ふつうの予定にもどります。「回べつ」に殿堂入りの数が出ます。
- **4年の漢字は抜き取り確認**：各回40語のうち、その回の10字から1語ずつの10語を先に出します。9語以上○ならその回の残り30語は出さず、8語以下ならその回の40語を全部出します。5年上の漢字は全部出します。
- **正誤の練習（社会・テスト対策）**：組分けテストの選択肢と同じ形の文（126文。第1〜11回）を見て、○か×かを答えます。×の文には、どこがちがうかの説明がつきます。10問ずつで、2割は前の範囲から出ます。まちがえた文は最後にもう一度出ます。教科のメニューの「組分け回」にいつでもあります。ふだんの一問一答は知識をためる練習、正誤の練習はテストの形に慣れる練習、という分け方です。
- **見くらべの練習（社会・テスト対策）**：似ていてまぎらわしいものの組（59組。土偶と埴輪、義家と義朝、道長と頼通、文永と弘安、馬借と土倉、三大改革など）から、説明を読んでどれのことかをえらびます。答えたあとに組の全部の見くらべが出ます。10問ずつで、2割は前の範囲から。まちがえた組は最後にもう一度出ます。「組分け回」にあります。
- **社会の漢字の強化**：テストで字をまちがえた語（荘園・御恩・御家人・墾田永年私財法・不輸・琉球王国など21語）には、答えを見たときに「字に注意」が赤く出ます。これらの語は、漢字ミス（△）の語と同じように「社会の漢字の練習」に入り、そこで○になるまで出ます。
- 答えのわくの指定は、テストと同じ形で出ます（「漢字3字」「ひらがな4字」「カタカナ4字」「ことばで答える」）。
- **とことん練習**：苦手な問題を、○が2回続くまでくり返します。印つきの語（×の多い順）が先に出ます。通常回はいまの回から20問、組分け回は組分け範囲から30問（2割は前の範囲から）です（下の「とことん練習」）。
- 社会の1周目は浅く速く解くので、1周目の×・△は「印つき」にしません（あとから増えて「きょうの1周」で初めて解いた語も同じ）。2日目からの周回で×・△になった語に印がつきます。
- 出る順番：社会は教科書の順、ことばはカードの順、漢字はばらばらに出ます。順番で答えを覚えてしまわないためです。教科ごとに「ノート」の設定で「教科書の順」と「ばらばら」を切りかえられます。
- 漢字は、文の【 】の部分を漢字で書きます。答えのわくは1つの長方形で、字数も送りがなも見せません（送りがなが必要な語は、送りがなも自分で書く）。社会の語は、字数ぶんのマスが出ます。ことばは、意味と用例を見て、ことばを答えます（ひらがなでもよい）。第11回の外来語は、カタカナで答えます（字数ぶんのマスが出ます）。
- **印と次に出す日は、その語のその日の最初の答えだけで決めます**（どのメニューでも。1.26.0から）。最初の答えが×・△なら印がつき、同じ日にあとで○になっても印は残ります。最初が○なら○です。同じ日の2回目からの答えでは、印は変わりません。印は、別々の日の最初の答えで○が2回続くと消えます。「ノート」の「印をつける」は、いつでも使えます。
- 今日△と×をつけた語は、「ノート」のいちばん上の「今日まちがえた語」に、まちがえた順で並びます。「もう一度解く」で、その語だけをまとめて解き直せます（×は3問あと・△は6問あとにもう一度出ます。1回に4回まで）。そのあと今日のうちに○になった語には「あとで○」が付きます。次の日になると空になります。

## 教科のメニュー（通常回と組分け回）

「きょう」の画面で教科を押すと、その教科のメニューが出ます。

| まとまり | 中身 |
| --- | --- |
| 通常回（その教科のいまの回） | 社会：1周目（その回で最初の1周目が終わるまでは、これだけ）・きょうの1周。漢字：新しい語。ことば：カード。3教科とも：復習（20語）、とことん練習（いまの回から20問） |
| 組分け回（組分け範囲） | とことん練習（30問。2割は前の範囲から）、正誤の練習・見くらべの練習（社会） |

- テストの7日前からは、組分け回が上に出ます。志望校判定テストの前7日は、組分け回の代わりに「これまでの範囲」（とことん練習）が上に出ます。
- 点線のボタン（目安を達成したあとの復習・とことん練習・正誤の練習・見くらべの練習）は、やりたいときにやる練習です。目安を達成したあとの復習は、積み上げの輪に入ります。
- 1.26.0 で、集中練習・復習のつづき・積み上げ・組分け範囲の弱点のボタンはなくしました（復習ととことん練習にまとめた）。
- 下の「きょう」のタブを押すと、教科のボタンの画面にもどります。
- 社会の第10回のように、その教科の新しい回がない週は、その教科のいちばん新しい回（第9回）が「通常回」になります。

## とことん練習

苦手な問題を、○が2回続くまでくり返す練習です。解いたことのある問題から、**印つきの語**（×の多い順）を先に、そのあとは**次のテストの日に思い出せる見込み**の低い順に出します。見込みは、英語学習ドリル（english-drill）と同じ FSRS という計算で、これまでの記録をはじめから計算し直して出します（○＝普通、△＝難しい、×＝もう一度）。テストの予定がないときは、7日後で計算します。

| | 通常回 | 組分け回 |
| --- | --- | --- |
| 範囲 | いまの回 | 組分け範囲（1回の2割は前の範囲から）。志望校判定テストの前7日は、これまでの範囲 |
| 1回の数 | 20問（設定で10問・30問） | 30問（設定で20問・40問） |

- 出し直し：×は3問あと、△は6問あと。×か△があった問題は、○が2回続いたら外れます（1回目の○のあと、5問あとに確かめる）。最初から○なら1回で外れます。回数の上限はなく、全部の問題が外れたら終わりです。
- 何度でもできます。その日にとことん練習で出た問題は、その日の「続けて」には入りません。
- 出し直しの問題には「もう一度」の札が付きます。

### 記録のしかた

- 1回目の答えはメニューごとの種類（`lap1` 1周目・`lap` きょうの1周・`new` 新しい語・`deck` カード・`review` 復習・`tokoton` とことん練習・`free` 回べつの20問など）で、出し直しの答えは末尾に `:r` を付けて記録します（`review:r`・`tokoton:r`・`weak:r`）。記録の形（[問題の番号, 採点, 時刻, 種類]）と同期のしくみは変わりません。前の版の `focus`（集中練習）・`back`（積み上げ・復習のつづき）の記録も、そのまま使います。
- 毎日の予定（1→3→7…日後）、印、殿堂入り、社会の「2日続けて○」には、その語の**その日の最初の答え**だけを使います（1.26.0 から、すべてのメニュー。前の日の記録にも、さかのぼって使います）。出し直しの答えも使いません。例外は「印をつける」（いつでも使う）と、社会の漢字の練習（同じ日の2回目からの○は、漢字ミスの数にだけ使う）です。
- FSRS の見込みには、出し直しもふくめて全部の答えを使います（「印をつける」で付けた印は使いません）。バッジの「解いた数」にも数えます。
- 社会の最初の1周目が終わった回は、設定の `lap1`（例：`11`）に入れて、端末どうしで同期します。1.26.0 より前に1周目を始めた回は、8割以上解いていれば終わったものとします。
- 11月12日 1:45〜4:00 の記録（1.26.0 にしたあと、ためしに触った分）は取り消してあります。この時間帯の答え・バッジは、どの端末でも使わず、クラウドに残っていても取りこみません。

## きょうの3つの輪とバッジ

毎日の目標を3つの輪で表します。3つともそろった日が「輪がそろった日」です。

| 輪 | そろう条件 |
| --- | --- |
| 新しい語 | 今週の回の新しい語を20語解く（のこりが少なければ、のこり全部）。ことばのカードも、はじめて解いた日は数に入る |
| 復習 | その日の復習の目安（60語）を、教科のメニューの「復習」で解く。前の範囲の語もふくむ |
| 積み上げ | 目安をこえて、さらに復習で10語解く（目安を達成したあとの点線の「復習」） |

- がんばりの記録は「バッジ」の画面にたまります。まだのバッジをおすと、もらえる条件が出ます。
- バッジがもらえると、大きなメダルがくるくる回って出てきます。出るのは、問題を解き終わった画面です。
- もらったバッジをおすと大きくなり、指でなぞると回せます。うら側には、もらった日が出ます。
- 音は「ノート」の設定で消せます。タブレットが消音のときは鳴りません。
- バッジは、続けた日数、解いた数、定着した語の数、回ごとの達成、弱点の克服、組分けテストへの取り組みに付きます。○の数や正答率には付きません。
- お休み券：1か月に決めた日数（はじめは2日）までは、休んでも連続の日数がとぎれません。休んだ日に自動で使います。
- バッジを入れる前の日は、20問以上解いた日を「輪がそろった日」として数えます。
- 輪の目標とお休み券の日数は「ノート」の設定で変えられます。はじめは、新しい語20語・復習60語・積み上げ10語・お休み券は月2日です。
- **シークレットバッジ**：バッジの画面のいちばん下に「？？？」で出ます。取るまでは名前も条件も出ません（条件は保護者向けの仕様書に書いてあります）。もらうと「シークレットバッジ　ゲット！」の演出が出ます。
- シークレットバッジのメダルの絵は、保護者が用意した画像から作ったもので、権利の都合で公開ページ（GitHub）には入れていません。暗記カードと同じく、`バッジの絵_ひみつ.json` を「ノート」の「暗記カード」から取り込みます（**GitHubに上げない**）。取り込む前や、まだ絵がとどいていない端末では、黒と金の文字のメダルで出ます。

## テストの点数とバッジ

- 「ノート」の「テストの点数」に、週テストと組分けテストの点数を入れます。受けた教科だけでかまいません。
- 週テストで、どれかの教科か4科合計の点数がこれまでの最高をこえると、「週テスト自己ベスト」のバッジがとどきます。最初の1回は、くらべる相手がないので対象外です。
- 組分けテストで「S」をえらんで記録すると、「組分けSクラス」のバッジがとどきます。
- まちがえて入れた記録は「消す」を2回おすと消えます。その記録でもらったバッジも消えます。

## 印刷用シート

- 「ノート」の「印つきの語」にある「印刷用シート」をおします。
- 対象は、今日まちがえた語・印つきの語・社会の漢字ミスの語・今週の回のすべての語からえらべます。「今日まちがえた語」の欄の「印刷用シート」から開くと、今日まちがえた語が選ばれた状態で開きます。
- 形は、答えをかくす（書きこみ用）・答えつき・答えと解説つきからえらべます。
- 「ばらばら」にした教科（はじめは漢字）は、シートを開くたびに並びが変わります。開いている間は、書きこみ用と答えつきが同じ並びなので、続けて印刷すれば答え合わせに使えます。

## 模擬テスト

- 「きょう」の「ほかの練習」にある「模擬テスト」から始めます。組分けテストと同じ形の、社会のテストです。
- 記号の問題は画面でえらび、書く問題は紙に書きます。終わったら答え合わせをして、書いた問題は自分で○×をつけます。
- 第1〜4回は40問・35分です。第6〜9回は48問・42分です（11月8日の組分けテストの範囲）。
- 第11〜14回（12月13日の組分けテストの範囲）は、いまは第11回の12問＋前の範囲（鎌倉〜江戸時代(1)）の10問です。第12〜14回は、資料がそろいしだい加えます。

## 端末どうしの同期

「ノート」の「端末どうしの同期」でログインすると、タブレットとパソコンなど、ログインした端末の記録がそろいます。解答の記録、設定、輪がそろった日、バッジ、テストの点数が対象です。

- ログインは端末ごとに1回だけです。メールアドレスとパスワードは、Firebase に登録したものを使います。パスワードは、この同期のためだけのものにしてください。
- ログインしなくても、ドリルはこれまでどおり使えます。インターネットにつながらないときも解けて、つながったときにまとめて送られます。
- 画面の上に、いまの様子が出ます。

| 表示 | 意味 |
| --- | --- |
| 同期ずみ | クラウドと同じ記録になっている |
| 同期中… | 送っているところ、またはつないでいるところ |
| オフライン | インターネットにつながっていない。記録は端末に残り、あとで送られる |
| 同期の確認待ち（ノート） | はじめて合わせる端末に記録があるので、送ってよいかを「ノート」でたずねている |
| 同期が止まっています（ノートでログイン） | ログインが切れた。「ノート」でログインし直す |

### はじめて合わせるとき

1. **ふだん学習に使っている端末（タブレット）で先にログイン**します。「この端末にだけある記録が ○件あります」と出るので、「送って合わせる」をおします。
2. そのあとで、ほかの端末でログインします。記録のない端末は、何も聞かれずにタブレットと同じ記録になります。
3. ほかの端末に、**ためしに解いた記録**があると、同じように「送って合わせますか？」と聞かれます。合わせた記録は取りのぞけないので、「送らない（ログアウト）」をえらび、下の手順でその端末の記録を消してから、ログインし直してください。

### ためしに使った端末の記録を消す（パソコンの Chrome・Edge）

1. ドリルのページを開き、アドレスバーの左はしのアイコンをおす。
2. 「Cookie とサイトデータ」→「デバイス上のサイトデータを管理」で、`onokatsuya-77.github.io` のデータを削除する。
3. ページを読み込み直す。「ノート」のいちばん下が「記録 0件」になっていれば、消えています。

この手順は、**その端末の記録をすべて消します**。ふだん学習に使っている端末では行わないでください。

### 記録の守り方

- 記録を読み書きできるのは、ログインした本人だけです（Firebase の「ルール」で、登録した1人のユーザーに限っています）。
- ドリルのページそのものは、だれでも開けます。ほかの人が開いても、その人の端末に、その人だけの記録ができるだけです。

## 暗記カード（塾の補助プリント）

塾の「漢字とことば」暗記カードの絵を、ことばの問題に使えます。カードのある語は、カードのおもて（○のヒントつき）が出て、「答えを見る」でうら（答え）に返ります。うらの絵をおすと、おもてに戻ります。記録は、これまでのことばの問題の記録として残ります。

- カードの絵は塾の教材なので、**公開ページ（GitHub）には入れません**。ログインした本人だけが読めるFirebaseに置き、各端末にも保存します。いちど保存した端末では、インターネットがなくても出ます。
- 「回べつ」のことばの各回にある「カード」で、その回のカードを表紙から順にめくれます。めくるだけで、記録はつきません。
- 「ノート」の設定「ことばの出し方」で、「暗記カード」と「文字」を切りかえられます。
- **当面は、塾のカードがある語だけ**をことばの問題にしています（第1〜11回で178語）。「ノート」の設定「ことばで出す語」を「すべての語」にすると、下の「ドリルのカード」の語（54語。第10回 総合のカードができた8語は、塾のカードの語として出ています）と、第8回の同音異義語でカードのない3組、第9回の同訓異字でカードのない2組（いる・さげる）、第11回の外来語でカードのない17語（キャンセル・リテラシーなど、テキストだけにある語）も出ます。
- 第5回 総合のカードにだけある2語（たなびく・胸がすく）を、ことばの第5回として加えました。

### カードの取り込み方（1回だけ）

1. カードのファイル（例：`暗記カード_5年下_第1-6回.json`、`暗記カード_5年下_第7回.json`、`暗記カード_5年下_第8回.json`、`暗記カード_5年下_第9回.json`、`暗記カード_5年下_第10回.json`、`暗記カード_5年下_第11回.json`、`暗記カード_5年上_第1〜5回.json`）を受け取る。**このファイルはGitHubに上げない。**
2. パソコンでドリルを開き、「ノート」の「端末どうしの同期」でログインする。
3. 「ノート」の「暗記カード」で、カードのファイルを選び、「取り込む」をおす。
4. タブレットは、ログインしていれば自動でカードを受け取ります。「暗記カード」の欄に「この端末に未保存」が出なくなれば終わりです。

新しい回のカードは、PDFをClaudeに渡すと、取り込み用のファイルにします。まちがえて取り込んだ回は、「暗記カード」の欄の「消す」を2回おすと消えます。
5年上のカード（19回分・498枚）は、`暗記カード_5年上_第1〜5回.json`・`第6〜10回.json`・`第11〜15回.json`・`第16〜19回.json` の4ファイルに分けてあります。1ファイルずつ、同じ手順で取り込みます（1ファイル10〜20MB。取り込みに数分かかることがあります）。

## つきそう人へ

- 「ノート」の設定で、**今週の回**を毎週切りかえてください。新しい回を入れた版に更新したとき、今週の回がそれまでの最新の回になっていれば、自動で新しい回に切りかわります（「きょう」にお知らせが出ます）。前の回を選んであるときは動きません。
- テストの日程（組分けテスト 11月8日・12月13日・1月24日、志望校判定テスト 1月11日）は入れてあります。テストの7日前から、教科のメニューで組分け回（とことん練習・正誤の練習・見くらべの練習）を先に出します。とことん練習の並びも、次のテストの日を基準に計算します。
- 塾のプリントや週テストでまちがえた語は、「ノート」の検索から印をつけられます。
- ログインしていれば、記録はクラウドにも残ります。念のため、**月に1回は「ノート」→「記録をコピー」**で保管してください。
- ログインしていないときは、**週に1回**コピーしてください。ブラウザの閲覧データを消すと、その端末の記録は消えます。

## 中身

`index.html` 1ファイルだけで動きます。問題は各回の単元に沿って独自に作ったものです。
同期には Firebase（Authentication と Cloud Firestore）を使っています。`index.html` に書いてある Firebase の設定値は、公開してよい値です。記録は、ログインと Firestore のルールで守ります。
